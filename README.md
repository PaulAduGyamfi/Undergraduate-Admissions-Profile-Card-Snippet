# Undergraduate Admissions Profile Card Snippet

A frontend component built for Stony Brook University's Admissions website during a Software Engineer internship with the Dept. of Communication & Marketing.

## What This Project Accomplished

- Designed and built a reusable UI component to display admissions counselor profiles in a card-based layout
- Delivered a component that integrated into the university's existing admissions site, giving prospective students an easy way to identify and learn about their assigned counselor
- Worked within an existing production codebase and design system, adapting the component to match established site styling and conventions

## Technologies Used

- **Language:** JavaScript
- **Context:** Built and shipped within Stony Brook University's live admissions website

## What I Learned

This project was my introduction to building for a real, live production website rather than a standalone assignment — working inside someone else's existing codebase, respecting design constraints, and shipping a component used by actual site visitors.
